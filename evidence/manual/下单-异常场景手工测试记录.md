## 异常用例（空 / 超长 / 越权 / 负数 / 不存在 / 重复）
### 空 goods_id / quantity 缺省
- 请求：`POST /api/v1/orders`，`X-Demo-Account=buyer01`
- 入参：`{"quantity": 1}`
- 预期：`PARAM_ERROR`
- 实际 HTTP：`200`
- 实际响应：`{"code":"M-04","message":"一单只能购买一种商品","data":null}`
- 判定：**DIFF（预期与实际不一致，边界行为如实登记，不改动业务代码）**

### 负数 goods_id
- 请求：`POST /api/v1/orders`，`X-Demo-Account=buyer01`
- 入参：`{"goods_id": -1, "quantity": 1}`

- 实际 HTTP：`400`
- 实际响应：`{"code":"PARAM_ERROR","message":"请求体不是合法 JSON 或字段类型不正确：json: cannot unmarshal number -1 into Go struct field createOrderReq.goods_id of type uint64","data":null}`
