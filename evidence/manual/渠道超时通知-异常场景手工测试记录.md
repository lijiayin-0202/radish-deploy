## 异常用例（空 / 超长 / 越权 / 负数 / 不存在 / 重复）
### 空 channel_trade_no
- 请求：`POST /api/v1/payment/timeout`，`X-Demo-Account=mock01`
- 入参：`{"order_no": "ORD-1794466691679833800-1001-1", "channel_trade_no": "", "reason": "x"}`
- 预期：`PARAM_ERROR`
- 实际 HTTP：`400`
- 实际响应：`{"code":"PARAM_ERROR","message":"order_no 与 channel_trade_no 均不能为空","data":null}`
- 判定：**PASS（预期与实际一致）**

## 边界说明

- 以上为开发会话内的手工执行记录，**不是独立测试 Agent 会话产物，也不是第 2 轮 Apipost 正式证据**。
- 未在真实 MySQL(InnoDB) 下复跑，唯一键冲突、行锁并发与重启后查询证据仍属环境缺失。
- 判定为 `DIFF` 的条目如实登记边界行为差异，不改动业务代码、不弱化断言、不删除失败用例。
- 不改写订单状态消除异常、不删除业务记录、不新增业务状态机。
